## What is Statis?

Statis is a decorator-based governance layer for production AI agents.

```python
from statis_ai import gate

@gate(action_type="stripe_refund")
def refund(charge_id: str, cents: int) -> dict:
    return stripe.refunds.create(charge=charge_id, amount=cents)
```

That's it. When your agent calls `refund()`, Statis intercepts, evaluates your policy rules, and either:

- **Approves** automatically (rule says it's safe), or
- **Sends a signed URL** to a human for approval, or
- **Denies** the action before it runs

Every outcome — approved, denied, escalated — writes a tamper-evident receipt.

## The four concepts

Statis does four things in sequence every time a gated function is called:

1. **Propose** — the decorator captures the function name, arguments, and caller context
2. **Approve** — your policy rules evaluate; a human approves if rules say ESCALATE
3. **Receipt** — the outcome is written to the ledger atomically with execution
4. **Graduation** — after 3 identical approvals, a YAML policy rule is auto-generated

## What Statis is not

Statis is not a prompt guard, a context compressor, or a token meter. If you need offline
pre-call hygiene (no network, no auth), see [statis-kit](/statis-kit) — a separate package
for exactly that.
