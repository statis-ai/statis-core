## Prerequisites

- PostgreSQL running locally
- Python 3.11+
- Node 18+ (for the Console)

## 1. Clone and install

```bash
git clone https://github.com/statis-ai/statis-core.git
cd statis-core/api
pip install -r requirements.txt
```

## 2. Run migrations and seed an API key

```bash
alembic upgrade head
python scripts/seed_admin.py
# → STATIS_API_KEY=st_...
```

## 3. Start all three services

```bash
# Terminal 1 — API
cd api && fastapi run app/main.py

# Terminal 2 — Console
cd console && npm install && npm run dev

# Terminal 3 — Execution worker
python -m worker.execute
```

## 4. Install the SDK

<CodeGroup>
```bash Python
pip install statis-ai
```
```bash TypeScript
npm install statis-ai
```
</CodeGroup>

## 5. Run the demo

<CodeGroup>
```python Python
from statis import StatisClient, ActionDeniedError, ActionEscalatedError

with StatisClient(api_key="st_...") as client:
    try:
        receipt = client.execute(
            action_type="retention_offer",
            target={"entity_type": "account", "entity_id": "acct-42"},
            parameters={"discount_pct": 20},
            agent_id="csm-agent-v2",
            target_system="stripe",
        )
        print(f"Executed — hash: {receipt.hash}")

    except ActionDeniedError as e:
        print(f"Policy denied: {e.receipt.rule_id}")

    except ActionEscalatedError as e:
        print(f"Needs human review — action_id: {e.action_id}")
```
```typescript TypeScript
import { StatisClient, ActionDeniedError, ActionEscalatedError } from "statis-ai";

const client = new StatisClient({ api_key: "st_..." });

try {
  const receipt = await client.execute({
    action_type: "retention_offer",
    target: { entity_type: "account", entity_id: "acct-42" },
    parameters: { discount_pct: 20 },
    agent_id: "csm-agent-v2",
    target_system: "stripe",
  });
  console.log(`Executed — hash: ${receipt.hash}`);

} catch (e) {
  if (e instanceof ActionDeniedError) console.log(`Denied: ${e.receipt.rule_id}`);
  if (e instanceof ActionEscalatedError) console.log(`Escalated: ${e.action_id}`);
}
```
</CodeGroup>

`execute()` is a single blocking call: propose → evaluate → poll until done → return receipt.

## 6. Inspect the receipt

The Console runs at `http://localhost:3000`. Search for entity type `account`, ID `acct-42`:

- **Actions tab** — see the action contract with its status
- **Receipt tab** — decision banner, conditions pass/fail, entity state snapshot, SHA-256 hash

## What just happened?

1. `POST /actions` — created an action contract for `acct-42`
2. `POST /actions/{id}/evaluate` — policy engine evaluated against `churn_retention_v1` rule
3. Worker picked up the APPROVED action, acquired a distributed lock, called the Stripe adapter
4. Receipt written with SHA-256 hash — tamper-evident record of everything

<Note>
  The demo uses the `churn_retention_v1` policy rule which requires `churn_risk=true` and `ltv >= 1000` on the entity state. If evaluation returns DENIED, post a `account.churn_risk_updated` event first to set those values, or see the [end-to-end demo script](https://github.com/statis-ai/statis-core/blob/main/examples/retention_demo.py).
</Note>
