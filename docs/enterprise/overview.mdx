## How to get Enterprise

Enterprise is contract-driven. We do a scoping call, confirm deployment requirements
(VPC region, SSO provider, compliance scope), and issue a contract.

## Available now vs roadmap

Most Enterprise features exist in the codebase today (~70%). A few are contract-driven
only because they require dedicated infrastructure setup per customer:

- **VPC deploy** — Kubernetes manifests ready; requires your cloud account access
- **SCIM** — API implemented; requires your IdP's provisioning credentials
- **SOC2-export receipts** — ledger export format spec in progress (Q3 2026 target)

## Self-hosted alternative

If you need full data sovereignty without an Enterprise contract, see the
[self-hosting guide](/self-host/quick-deploy). The self-hosted distribution includes
the full policy engine, receipt ledger, and approval page — without SSO or SCIM.
