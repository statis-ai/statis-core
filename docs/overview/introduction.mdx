Statis is the missing reliability layer for AI automations: **publish facts once → golden state → push changes → replayable audit**.

<Note>
Instead of tangling your code with 10 different database updates and fragile event listeners, Statis unifies them into a single write path.
</Note>

## Why Statis?

- **Semantic Ingestion:** You just tell Statis an event happened (`account.created`, `ticket.resolved`).
- **Materialized State:** Statis instantly updates a single, coherent golden state.
- **Outbox Webhooks:** Statis pushes incremental changes reliably to your downstream receivers.

## The Core Concept

<Steps>
  <Step title="1. Your AI Agent acts">
    The agent completes a task and sends a clean JSON payload to Statis.
  </Step>
  <Step title="2. Statis handles the rest">
    Statis synchronously updates Postgres, ensuring data integrity.
  </Step>
  <Step title="3. Downstream services trigger">
    The worker picks up the state diff and sends webhooks to your CSM tools, billing systems, etc.
  </Step>
</Steps>
