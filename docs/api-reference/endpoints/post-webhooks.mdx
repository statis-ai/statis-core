---
title: "Create Webhook"
api: "POST /webhooks"
description: "Register a webhook endpoint to receive event notifications."
---

## Request body

<ParamField body="url" type="string" required>
  The HTTPS URL to deliver webhook payloads to. Must be a valid URL.
</ParamField>

<ParamField body="events" type="array" required>
  List of event types to subscribe to. Valid values: `action.completed`, `action.denied`, `action.escalated`. At least one event is required.
</ParamField>

## Response

<ResponseField name="id" type="string">Auto-generated webhook ID.</ResponseField>
<ResponseField name="tenant_id" type="string" />
<ResponseField name="url" type="string" />
<ResponseField name="events" type="array" />
<ResponseField name="is_active" type="boolean">Always `true` on creation.</ResponseField>
<ResponseField name="created_at" type="string">ISO 8601 timestamp.</ResponseField>

<RequestExample>
```bash cURL
curl -X POST https://api.statis.dev/webhooks \
  -H "X-API-Key: st_..." \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/hooks/statis",
    "events": ["action.completed", "action.denied"]
  }'
```
</RequestExample>

<ResponseExample>
```json 201
{
  "id": "wh-abc123",
  "tenant_id": "tenant_a1b2c3d4e5f6",
  "url": "https://example.com/hooks/statis",
  "events": ["action.completed", "action.denied"],
  "is_active": true,
  "created_at": "2024-01-15T10:00:00Z"
}
```
</ResponseExample>
