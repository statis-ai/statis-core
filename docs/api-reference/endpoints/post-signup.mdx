---
title: "Sign Up"
api: "POST /admin/signup"
description: "Create a new tenant account. Returns a tenant ID and master API key."
---

## Request body

<ParamField body="email" type="string" required>
  Email address for the account.
</ParamField>

<ParamField body="password" type="string" required>
  Password for the account.
</ParamField>

<ParamField body="project_name" type="string" required>
  Name of the project or organization.
</ParamField>

## Response

<ResponseField name="tenant_id" type="string">The newly created tenant identifier.</ResponseField>
<ResponseField name="api_key" type="string">Master API key. This is the only time the raw key is returned -- store it securely.</ResponseField>
<ResponseField name="label" type="string">Label for the generated key (e.g. `"Master Key (you@example.com)"`).</ResponseField>

<RequestExample>
```bash cURL
curl -X POST https://api.statis.dev/admin/signup \
  -H "Content-Type: application/json" \
  -d '{
    "email": "you@example.com",
    "password": "s3cure-passw0rd",
    "project_name": "My AI Project"
  }'
```
</RequestExample>

<ResponseExample>
```json 201
{
  "tenant_id": "tenant_a1b2c3d4e5f6",
  "api_key": "st_aBcDeFgHiJkLmNoPqRsTuVwXyZ...",
  "label": "Master Key (you@example.com)"
}
```
```json 409
{ "detail": "An account with this email already exists." }
```
</ResponseExample>
