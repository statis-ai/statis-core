---
title: "Approve Escalation"
api: "POST /actions/{action_id}/approve"
description: "Human approves an ESCALATED action. Moves status to APPROVED for worker pickup."
---

## Path parameters

<ParamField path="action_id" type="string" required>
  The escalated action to approve. Must be in `ESCALATED` status.
</ParamField>

## Request body

<ParamField body="reviewer_id" type="string" required>
  Identifier of the human reviewer approving the action.
</ParamField>

<ParamField body="note" type="string">
  Optional review note — stored in the escalation audit log.
</ParamField>

## Response

<ResponseField name="review_id" type="string" />
<ResponseField name="action_id" type="string" />
<ResponseField name="reviewer_id" type="string" />
<ResponseField name="reviewer_decision" type="string">Always `APPROVED`.</ResponseField>
<ResponseField name="reviewer_note" type="string | null" />
<ResponseField name="reviewed_at" type="string" />

<RequestExample>
```bash cURL
curl -X POST https://api.statis.dev/actions/act-abc123/approve \
  -H "X-API-Key: st_..." \
  -H "Content-Type: application/json" \
  -d '{
    "reviewer_id": "ops-team@company.com",
    "note": "Verified churn risk manually — approve."
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "review_id": "rev-def456",
  "action_id": "act-abc123",
  "reviewer_id": "ops-team@company.com",
  "reviewer_decision": "APPROVED",
  "reviewer_note": "Verified churn risk manually — approve.",
  "reviewed_at": "2024-01-15T10:30:00Z"
}
```
```json 409
{ "detail": "Action is not in ESCALATED status" }
```
</ResponseExample>
