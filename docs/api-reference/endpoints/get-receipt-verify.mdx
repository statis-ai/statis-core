---
title: "Verify Receipt"
api: "GET /receipts/{receipt_id}/verify"
description: "Verify the SHA-256 hash integrity of a receipt. Does not require authentication."
---

## Path parameters

<ParamField path="receipt_id" type="string" required>
  The receipt ID to verify (not the action ID).
</ParamField>

## Response

<ResponseField name="receipt_id" type="string" />
<ResponseField name="action_type" type="string">The action type from the associated action contract.</ResponseField>
<ResponseField name="tenant_id_prefix" type="string">First 8 characters of the tenant ID.</ResponseField>
<ResponseField name="status" type="string">The receipt decision (`APPROVED` or `DENIED`).</ResponseField>
<ResponseField name="evaluated_at" type="string">ISO 8601 timestamp of when the receipt was created.</ResponseField>
<ResponseField name="hash" type="string">The stored SHA-256 hash.</ResponseField>
<ResponseField name="hash_valid" type="boolean">`true` if the recomputed hash matches the stored hash.</ResponseField>
<ResponseField name="rule_ids_evaluated" type="array">List of rule IDs that were evaluated. Empty if no rule matched.</ResponseField>

<RequestExample>
```bash cURL
curl https://api.statis.dev/receipts/rcpt-xyz789/verify
```
</RequestExample>

<ResponseExample>
```json 200
{
  "receipt_id": "rcpt-xyz789",
  "action_type": "retention_offer",
  "tenant_id_prefix": "tenant_a",
  "status": "APPROVED",
  "evaluated_at": "2024-01-15T10:00:01Z",
  "hash": "a3f8b2c1d4e5...",
  "hash_valid": true,
  "rule_ids_evaluated": ["churn_retention_v1"]
}
```
```json 404
{ "detail": "Receipt 'rcpt-xyz789' not found" }
```
</ResponseExample>
