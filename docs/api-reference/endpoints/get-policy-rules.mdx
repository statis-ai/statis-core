---
title: "List Policy Rules"
api: "GET /policy-rules"
description: "List all policy rules for the authenticated tenant."
---

## Query parameters

<ParamField query="action_type" type="string" optional>
  Filter by action type (e.g. `"retention_offer"`).
</ParamField>

## Response

Returns an array of policy rules, ordered by priority descending then rule_id.

<ResponseField name="rule_id" type="string" />
<ResponseField name="rule_version" type="string" />
<ResponseField name="action_type" type="string" />
<ResponseField name="conditions" type="object" />
<ResponseField name="decision" type="string" />
<ResponseField name="priority" type="integer" />
<ResponseField name="active" type="boolean" />
<ResponseField name="description" type="string | null" />
<ResponseField name="created_at" type="string">ISO 8601 timestamp.</ResponseField>

<RequestExample>
```bash cURL
curl https://api.statis.dev/policy-rules?action_type=retention_offer \
  -H "X-API-Key: st_..."
```
</RequestExample>

<ResponseExample>
