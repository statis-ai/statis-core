---
title: "List Webhooks"
api: "GET /webhooks"
description: "List all active webhooks for the authenticated tenant."
---

## Response

Returns an array of active webhook registrations, ordered by `created_at` descending.

<ResponseField name="id" type="string" />
<ResponseField name="tenant_id" type="string" />
<ResponseField name="url" type="string" />
<ResponseField name="events" type="array" />
<ResponseField name="is_active" type="boolean" />
<ResponseField name="created_at" type="string">ISO 8601 timestamp.</ResponseField>

<RequestExample>
```bash cURL
curl https://api.statis.dev/webhooks \
  -H "X-API-Key: st_..."
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "wh-abc123",
    "tenant_id": "tenant_a1b2c3d4e5f6",
    "url": "https://example.com/hooks/statis",
    "events": ["action.completed", "action.denied"],
    "is_active": true,
    "created_at": "2024-01-15T10:00:00Z"
  }
]
```
</ResponseExample>
