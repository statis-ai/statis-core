---
title: "List API Keys"
api: "GET /admin/api-keys"
description: "List all API keys for the authenticated tenant. Keys are shown as previews -- full keys are never returned after creation."
---

## Response

Returns an array of API key metadata, ordered by `created_at` descending.

<ResponseField name="id" type="string">Key record ID.</ResponseField>
<ResponseField name="tenant_id" type="string" />
<ResponseField name="label" type="string | null" />
<ResponseField name="role" type="string | null" />
<ResponseField name="agent_id" type="string | null" />
<ResponseField name="created_at" type="string">ISO 8601 timestamp.</ResponseField>
<ResponseField name="key_preview" type="string">Truncated key prefix (e.g. `"st_aBcDeF****"`).</ResponseField>

<RequestExample>
```bash cURL
curl https://api.statis.dev/admin/api-keys \
  -H "X-API-Key: st_..."
```
</RequestExample>
